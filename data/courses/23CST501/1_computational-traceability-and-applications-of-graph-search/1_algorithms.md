# Algorithms

- Sequence of computational steps that transform input to output.
- Well-defined computational procedure, takes some values as i/p as produces
  some value as o/p.

## Characteristics of a Good Algorithm

- Correctness – gives correct output
- Finiteness – finishes in finite no: of steps
- Efficiency – uses minimum time and resources
- i/p & o/p – takes i/p and gives o/p
- Definiteness – each step is clearly defined.

## Why Study Algorithms?

- Write efficient programs
- Solves real-world problems using computers
- Improve performance in terms of time & $\mathrm { m } / \mathrm { y }$
- Understand the core of computer science

## Types of Algorithms

1. Brute-force algorithm – simple and straight forward, eg: Linear search
2. Divide and conquer – divide problem $_ { - > }$ solve $_ - >$ combine, eg:
   merge sort
3. Greedy algorithm – choose best option at each step, eg: Kruskal algorithm
4. Dynamic programming – solves complex problems by breaking them into simpler
   sub problems, eg: Fibonacci series
5. Backtracking – tries all possibilities and removes bad options, eg: n-queens
   problem

## Time and Space Complexity

- Time complexity – how much time the algorithm takes?
- Space complexity – how much memory required?

## Analyzing Algorithms

Process of determining the efficiency of an algorithm in terms of space and time

## Why Analyze Algorithms

- To choose best algorithm for a problem
- To understand performance bottlenecks
- To compare two or more algorithms based on efficiency

## Types of Algorithm Analysis

- Worst case – maximum time taken on any input of size n
- Best case – minimum time taken
- Average case – expected time for typical input

## Performance Factors

- Size of input
- Type of input (sorted, unsorted, reverse)
- Hardware specifications
- Programming language / implementation
